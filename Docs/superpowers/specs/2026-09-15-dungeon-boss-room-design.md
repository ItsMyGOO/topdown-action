# 地下城最小闭环：Boss 房结构与门控

## 背景

地下城已有敌人/掉落/回城门，但全部混在一张平图上——没有「探索→清怪→Boss 房→战斗→奖励→撤离」的空间进程。本切片补齐结构，打通用户定义的最小闭环：进入地下城 → 探索 → 清理小怪 → 进入 Boss 房 → Boss 战 → 掉落装备 → 穿装提升 → 传送门开启 → 退出。

## 目标

- **地图分区**：640×380 分为「小怪区」（x<420）与「Boss 房」（x>420），中间一道带门洞的墙（StaticBody2D + 深色多边形视觉）
- **Boss 房门**：门洞处一扇门（StaticBody2D）；18 只小怪全部死亡后开启（碰撞关闭 + 视觉消失）
- **布局调整**：小怪铺左区网格；3 只 Boss 进右区；玩家出生与回城门在左下入口
- **进度提示**：复用交互提示标签显示进程——「清理小怪 x/18」→「Boss 房已开启，按住左键攻击」→「击败 Boss x/3 → 回城门开启」
- 闭环验证（引擎冒烟，全链路）：清怪→门开→杀 Boss→掉落稀有装备→拾取→穿戴→攻击/护甲数值提升→回城门开启

## 非目标

- 多房间/走廊生成、小地图、钥匙机关
- 墙体贴图（首版纯色多边形，像素化在美术期）

## 实现

- `Dungeon.tscn`：加 `Walls`（StaticBody2D 组）+ `BossGate`（StaticBody2D + 深色多边形）
- `WorldRoot`：小怪击杀计数 `_dungeonTrashDown/_dungeonTrashTotal`；全灭 `CallDeferred` 开门；`UpdateDungeonPrompt` 刷新进程文案；小怪/Boss 出生点改分区
- 门与墙的碰撞用 `SetDeferred("disabled", ...)` 避免 flushing queries 报错

## 测试

- 引擎冒烟（核心验收）：实例化地下城 → 断言门初始关闭 → 杀光 18 小怪 → 门开 → 杀 3 Boss → 掉落 ≥6 件稀有装备 → 拾取并穿戴 → 攻击伤害/护甲提升 → 回城门开启（visible+monitoring）
