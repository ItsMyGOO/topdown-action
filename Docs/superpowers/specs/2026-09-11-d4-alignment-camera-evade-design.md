# D4 对齐第一期：视角与闪避充能（含复刻路线图）

## 背景与总路线图

目标：以 2D 像素美术完整复刻暗黑4的核心体验（战斗/视角/成长/装备/世界），不符合 D4 的既有系统逐期替换。分系推进，每系可独立交付：

- ✅ 已落地：鼠标施法 6 槽技能、点地移动/点怪追击、等距 YSort 呈现、精英词缀、Boss、词缀装备、天赋盘、城镇/商人/存档
- **本期（第一期）**：跟随相机（视角缩放+边界）；删除体力系统，闪避改为 D4 式「充能+冷却回复」
- 第二期：生命药水（4 充能）、死亡惩罚（装备耐久/经验损失）、生命球掉落
- 第三期：2D 像素美术管线（角色 8 向序列帧、瓦片地图、光照），替换占位多边形
- 第四期：多职业（野蛮人/法师/游侠雏形）、主动技能解锁与强化（与天赋盘衔接）
- 第五期：世界等级/难度分层、地下城实例化、传送点网络、仓库
- 长线：Paragon 板、PvE 赛季循环、Boss 词缀机制库

## 本期目标

- **视角**：玩家跟随相机拉近视口（zoom 2.5，D4 式近景），开启地图边界限制（limit 0,0..640,380），保持既有平滑跟随
- **闪避充能替换体力**（对齐 D4：无体力，闪避为可积累次数+自动回复）：
  - `EvadeChargesModel`（纯逻辑）：默认 2 充能、每 5 秒回复一格；半充不可用；支持自定义上限/回复时长
  - `ActorContext.Stamina` → `ActorContext.Evade`；删除 `StaminaModel` 及其测试
  - `PlayerController`：闪避消耗由体力扣减改为 `Evade.TryConsume()`
  - `LevelingModel` 删除全部体力相关（常量/外部加成/期望值），`ApplyGrowth(mana, health)` 签名收敛
  - HUD「体力」标签改为「闪避 x/2」
  - 天赋「耐力」替换为「轻足」（fleetfooted，上限 2）：每级闪避回复 -1 秒（5→3），属性聚合新增回复缩减

## 非目标

- 药水/死亡惩罚/生命球（第二期）
- 像素美术资产与瓦片地图（第三期，本期限于相机行为）
- 主动技能/职业系统（第四期）

## 方案比选

- **方案 A（采用）**：`EvadeChargesModel` 浮点池（整数为可用充能，小数为进行中的回复），相机直接用 `Camera2D` 场景属性。
- 方案 B：闪避改为单充能固定冷却计时器。D4 是双充能，浮点池同时覆盖两格与进行中回复，更贴原作。
- 方案 C：相机逻辑自写插值。`Camera2D` 内置平滑/限制已满足，无需造轮子。

## 模块设计

### EvadeChargesModel（纯逻辑，`Game/Gameplay/Progression/`）

- 构造 `(int maxCharges = 2, float rechargeSeconds = 5f)`；`Available`（整数充能）；`TryConsume()`；`Tick(delta)` 按 `RechargeSeconds` 每格回复，钳制满值；非正 delta 忽略
- `RechargeSeconds` 可写（天赋「轻足」每级 -1 秒，下限 1.5 秒钳制在聚合侧或写入侧）

### 相机

- `Player.tscn` 的 `Camera2D`：`zoom = (2.5, 2.5)`、`limit_left/top = 0`、`limit_right = 640`、`limit_bottom = 380`（贴合当前世界内容范围），平滑 8.0 不变

### 存档兼容

- 闪避为运行时状态不持久化；无体力字段残留；旧档加载不受影响

## 测试计划

- `EvadeChargesModelTests`：初始满；消耗递减；空消耗拒绝；部分回复不可消耗；回复满值钳制；自定义上限/时长
- `TalentDatabaseTests`/`TalentStatsTests`/`TalentModelTests`（更新）：轻足映射 -1 秒/级
- `LevelingModelTests`（更新）：移除体力断言，保留法力/生命/读档幂等
- 引擎冒烟：双击闪避后第 3 次被拒、等待后回复可用；相机随玩家移动并受边界钳制

## 可裁剪性

- 闪避充能集中在单模型；相机为场景属性，均可独立回退
